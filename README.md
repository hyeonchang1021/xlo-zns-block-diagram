# XLO-ZNS 시스템 블록도

XLO-ZNS(Encryption-Aware Zone Placement for Zoned Namespace SSDs) 논문의 시스템 블록도입니다.
블록이나 흐름 이름을 누르면 그 부분의 역할, 동작, 식, 핵심 수치가 나옵니다.

- 페이지: https://hyeonchang1021.github.io/xlo-zns-block-diagram/
- 파일 하나(`index.html`)로 된 정적 페이지이고, 빌드 과정이 없습니다.
- 수치는 모두 시뮬레이터 값이며, 실제 장치의 절대 지연으로 인용할 수 없습니다.
